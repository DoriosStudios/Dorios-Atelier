# Concrete reference

`concrete_white.png` is the unchanged 16×16 source texture from
[Mojang/bedrock-samples](https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/resource_pack/textures/blocks/concrete_white.png).

Commit: `46ba6ea985fb5a92d79a9419198f10dda14c199d`.
SHA-256: `6ad27d2fa69de165de0aca11f7906d4b3ff25aed635c16a81d4971ce3a93fe73`.
Original Minecraft artwork belongs to Mojang/Microsoft; see the upstream license.

The generator preserves the native pixel arrangement and shifts the dominant RGB
to the selected Ascendant Technology panel fill or the locally selected spectrum
color. Copper, sand and slate describe colors: all 22 families behave as ordinary
stone/concrete.

`dye_powder_white.png` is another unchanged reference from the same commit,
at `resource_pack/textures/items/dye_powder_white.png`, SHA-256
`4e44ac3735fe264d695e448441896f754292958f8c3ce71ddb27a598a2946261`.
It was inspected for native item scale and pigment clusters. The new dyes are
drawn individually; this reference is not their shared silhouette.
